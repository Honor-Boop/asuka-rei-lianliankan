## v1.5.5

### 🐞 修复：立绘选择器被遮挡
- **现象**：v1.5.4 的「🖼 更换立绘」选择器打开后看不到面板（被玩法浮层自身的层级压住）
- **根因**：选择器面板被拼接到了玩法浮层容器**之外**，其 z-index 低于浮层
- **修法**：选择器面板移入玩法浮层内部（居中金边大面板 + 39 张缩略图网格）
- 附带：Esc 键可直接关闭选择器

### 🎛️ 承接 v1.5.4：玩法大厅重设计
- 四类型分组 + 每玩法专属配色图标 + 编号水印 + NEW 徽章 + 企画中预告
- 明日香元素：右侧立绘栏 → **已升级为全屏背景铺开**（选中的图库照片铺满整个选择界面，暗色渐变保证可读）
- 立绘选照：图库 39 张壁纸可选（角色筛选/随机），选择自动记忆
