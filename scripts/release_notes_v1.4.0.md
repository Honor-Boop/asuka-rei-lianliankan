## v1.4.0

### 💥 新玩法：三消 · AT碎裂
- 经典三消（match-3）：交换相邻宝石，凑齐 3 个以上同色即碎裂消除
- **连锁计分**：消除后宝石下落再自动成消，倍率递增 ×2、×3……连得越高越赚
- 三档难度：見習い 8×8·120 秒·目标 2000 / 正規隊員 8×8·90 秒·目标 3000 /
  使徒級 9×9·90 秒·目标 4000（6 色宝石）
- 六色宝石取自角色主题色（绫波蓝 / 明日香橙 / EVA 紫 / 力场绿 / NERV 金 / 桃红）
- **保证可玩**：盘面生成不含初始三连、永远存在可行棋；死局自动重排；
  另有 💡 提示与 🔀 手动重排（每局有限次数）
- 无效交换（不形成消除）会自动弹回；记录各难度最高分
