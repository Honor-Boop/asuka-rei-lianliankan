## v1.3.0

### 🧩 新玩法：拼图
- 用**图库里的壁纸**玩拼图：碎片打乱后复原成完整图像
- 三档难度：見習い 3×3 / 正規隊員 4×4 / 使徒級 5×5
- **实时联动图库**：每次开局随机选图，且通过接口实时拉取图库清单——
  **你在图库里新上传的图片，立刻就能被抽中当拼图**；图片被删除也会提示换图
- 壁纸自动裁成正方形切片（不变形）；点两块交换或拖动交换；
  按住「👁 预览」看原图；💡 提示归位一块；↩ 撤销；记录步数 + 用时

### 🃏 新玩法：接龙（Klondike）
- 经典接龙：7 列 + 右上 4 个基础叠（同花 A→K）+ 牌垛/弃牌堆，双姝扑克 52 张
- 三档难度：見習い**抽 1 张** / 正規隊員**抽 3 张** / 使徒級**抽 3 张且只能循环一轮**
- 列内红黑交替降序叠放、空列只放 K；**双击**牌直接送基础叠；
  「⤴ 自动收牌」一键收完当前能收的；提示、撤销、计时与步数记录

### 🖼 玩法大厅
- 新增「拼图」「接龙」两个入口，玩法总数达到 **8 个**：
  连连看 / 五珠对弈 / 观景挂机 / 蜘蛛纸牌 / 使徒扫雷 / 数独 / 拼图 / 接龙

### 📦 安装与更新
- 下载 `EVA-MiniGames-Setup-v1.3.0.exe` 覆盖安装即可（图库与战绩保留）
- 若被杀软拦截：程序未做代码签名，选择「允许运行」即可
