## v1.1.8

### 🆕 新玩法：数独 · 9×9
- 三档难度按开局提示格数：見習い訓練 44 格 / 正規隊員 34 格 / 使徒級 27 格（提示次数 5 / 3 / 1）
- 每局盘面随机生成并校验**唯一解**，不会出现多解或无解
- 操作：点格子后按键盘 1–9 或点下方数字键盘填数，方向键移动，Delete 擦除
- 选中格会同时高亮同行、同列、同宫以及全盘相同数字
- **候选数**模式（✎ / N 键）：记录小字备选，方便做推理笔记
- **即错提醒**：填错立即标红并计入「失误」（可关闭）
- 辅助：💡 提示填出一格正确答案、↩ 撤销（Ctrl+Z）、数字键盘显示每个数字还剩几个
- 计时 + 各难度最佳记录；零失误零提示通关有额外评价

### 🖼 图库扩展：每个游戏页都能看图
- 在**页面底部**新增与连连看页脚同格式的入口：`明日香 × 绫波丽 · 🖼 壁纸图库`
  （连连看 / 五珠 / 扫雷 / 蜘蛛纸牌 / 数独 / 观景 全部支持）
- 点开就地浏览，不用离开当前对局：角色筛选（绫波丽 / 明日香 / 美里，带张数）、
  缩略图墙、点图放大（←/→ 或滚轮翻页、Esc 关闭）
- 「设为背景」把看中的壁纸立刻换成当前背景；「打开完整图库」进管理页做上传/删除
- 快捷键 **G** 随时唤起图库

### 🎨 图标
