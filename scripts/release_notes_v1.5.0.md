## v1.5.0

### ⚔ 新玩法：EVA 出击 · 弹幕射击（动作射击）
- **Canvas 实时纵向射击**：驾驶 EVA 机体迎击使徒，火力**自动射击**，专心躲避弹幕
- **同步率系统**：命中/击破累积、随时间回落；**满 100% 进入暴走 6 秒**（射速翻倍 · 伤害 ×1.5 · 无敌 · 屏幕泛红），
  并**实时驱动右侧装饰栏的同步率面板**，暴走时面板转红色警报
- **AT 力场**：中和一次伤害，18 秒自动再充能（青绿六边形护罩）
- **使徒三档**（小型直冲 / 中型瞄准射击 / 重型扇形弹幕）+ **Boss 使徒三段形态**（瞄准扇射 → 螺旋弹幕 → 环形弹幕 + 召唤小型）
- 道具掉落（火力升级 / 力场充能 / 同步率）、三档难度 5/7/9 波、最佳分记录
- 操作：方向键 / WASD / **拖拽（含触屏）**，Shift 精确移动，`P` / `Esc` 暂停

### 🛡 新玩法：使徒来袭 · 塔防（策略塔防）
- **Canvas 实时塔防**：使徒沿固定通道从侵入点扑向 **NERV 本部**，撑过全部波次即作战完成
- **四类炮台 · 各 3 级**：零号机·绫波（减速控场）/ 二号机·明日香（高射速近战）/
  阳电子炮台（超远程高伤）/ AT 力场发生器（范围脉冲）
- **五型使徒**：小型 / 中型 / **重装**（护甲减伤）/ **分裂**（击破裂成两只小型）/ **Boss**（漏进本部扣 5 点）
- **经济**：击破得经费，建塔 / 升级 / 拆除（返还 70%）；**提前出击**把剩余备战时间兑换成经费（0.25 秒 = 1 经费）
- 三档难度 15/20/25 波，`⏩` 1×/2× 变速、暂停；分数与最佳记录
- 操作：点空地建造、点炮台升级/拆除，`Esc` 取消、`1–4` 快捷建造、空格提前呼叫
