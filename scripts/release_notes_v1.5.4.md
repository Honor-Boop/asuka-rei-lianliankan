## v1.5.4

### 🎛️ 玩法大厅重设计（选择界面）
- **类型分组**：15 个玩法按 ⚔动作·策略 / 🧩益智·消除 / 🀄纸牌·棋类 / 🧠记忆·放映 四组分区展示，面板加宽至 1280px 一屏显示
- **每玩法专属视觉**：彩色图标（hover 缩放）、左缘主色条、编号水印（01-15）、hover 按各自主题色发光
- **NEW 徽章**：2048 进化与记忆训练带脉冲标记

### 🧡 大厅明日香元素
- **右侧明日香立绘栏**：图库高清壁纸竖裁 + 渐变融入面板，「EVA-02 · PILOT: SORYU」铭牌，hover 缩放
- **明日香语录轮播**：5 条原作名台词（日语原句+中文翻译）每 5 秒轮换
- **EVA-02 · 適格者** 斜印章、面板描边转明日香红调

### 🖼️ 立绘选照（新功能）
- 立绘栏新增 **🖼 更换 / 🎲 随机** 按钮：从**图库全部壁纸**中选择大厅立绘（可按 明日香 / 绫波丽 / 美里 筛选）
- 选中的照片**自动记忆**（localStorage），下次打开保持；铭牌随角色自动切换（绫波→EVA-00 · PILOT: REI 等）
- 立绘图被删除时自动回退默认明日香立绘
