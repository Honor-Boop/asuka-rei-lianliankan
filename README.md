# 明日香&凌波丽连连看

以《新世纪福音战士》明日香与绫波丽为主题的**小游戏合集**（12 个玩法：连连看 / 五珠对弈 / 观景挂机 /
蜘蛛纸牌 / 使徒扫雷 / 数独 / 拼图 / 接龙 / 三消 / EVA 出击 / 使徒来袭 / AT 弹球），外加一个 **2K 壁纸图库**，
壁纸会作为页面的自动轮换背景。纯静态页面，无任何依赖，克隆后双击 `index.html` 即可游玩。

## 本地运行

直接双击 `index.html` 即可游玩（纯静态、离线可用）；
或起一个静态服务器后访问 <http://127.0.0.1:8765/index.html>：

```bash
python -m http.server 8765
```

### 桌面端启动（Windows）

双击 `start_lianliankan.vbs`（或在桌面创建指向它的快捷方式，图标用 `assets/icon.ico`）：
自动检测并在后台拉起本地服务（`serve.py`，带 no-store 禁缓存头），
然后以**应用窗口模式**（无地址栏）在 Edge/Chrome 中打开游戏，体验接近桌面程序。

### 图库添加 / 删除图片

通过桌面启动器（或 `python serve.py`）打开图库时：

- 点 **➕ 添加图片**：选分类（美里 / 绫波丽 / 明日香）并选择一个或多个图片文件
  （JPG / PNG / WEBP，单张 ≤ 30MB），上传后自动生成缩略图并登记进图库；
- 鼠标悬停在卡片上点右上角 **✕**，再点一次"确认?"即可删除该图。

上传与删除走 `serve.py` 的本地 API（仅监听 127.0.0.1），直接双击 `index.html`
（file:// 模式）时浏览功能不受影响，上传/删除需经本地服务。

## 游戏规则与功能

- 开局先选择难度：**見習い訓練**（6×4 · 12 种图案 · 90 秒）、**正規隊員**（8×6 · 24 种图案 · 210 秒）、**使徒級**（10×8 · 20 种图案 · 8 局连续 · 每局 150 秒）；
- 点击两张**相同图片**的牌，若能用**不超过 2 个拐点**的线连通（可以绕棋盘外圈）即消除，消除 **+3 秒**；选错直接取消选中；
- 连击：5 秒内连续消除，得分翻倍（+10 → +20 → …）；
- 使徒級第 2 局起，棋子每 10 秒按 右→下→左→上 轮换方向环绕位移（选中跟随、位移后保底可解），过关 +100 分，8 局全通触发"人类补完"通关特效；
- 💡 提示 ×3、🔀 洗牌（无可用配对时自动洗牌）、↻ 重开、⚙ 难度、📊 战绩（最近 60 局）、🖼 换背景、🔊 音效开关；
- 各难度最佳用时与战绩本地保存（localStorage）。

## 玩法大厅

打开页面先选玩法：连连看 / 五珠对弈 / 观景·挂机 / 蜘蛛纸牌 / 使徒扫雷 / 数独 9×9 / 拼图 / 接龙 / 三消 / **EVA 出击（弹幕射击）** / **使徒来袭（塔防）** / **AT 弹球（物理技巧）**（`🎮 玩法` 随时切换）。

### EVA 出击 · 弹幕射击（动作射击 · 新玩法）

- 驾驶 EVA 机体迎击来袭使徒：Canvas 实时滚动射击，**火力自动射击**，专心躲避弹幕即可；
- **操作**：方向键 / WASD 移动，也可直接拖拽机体（含触屏）；按住 Shift 半速精确移动，`P` / `Esc` 暂停；
- **同步率系统**：命中使徒缓慢上升、击破提升更快，随时间自然回落；**满 100% 进入暴走 6 秒**——射速翻倍、伤害 ×1.5、全程无敌且屏幕泛红，同时**实时驱动侧边装饰栏的同步率面板**（暴走时转红色警报）；
- **AT 力场**：自带一层力场中和一次伤害，18 秒后自动再充能（青绿六边形护罩）；力场破了才会真正掉耐久；
- **使徒**：小型（快速直冲）/ 中型（悬停瞄准射击）/ 重型（扇形弹幕）；最终 **Boss 使徒三阶段**（瞄准扇射 → 螺旋弹幕 → 环形弹幕 + 召唤小型）；
- **道具**：击破掉落 `P` 火力升级（最多 3 级）/ `A` 力场充能 / `S` 同步率 +25%；
- **三档难度**：見習い 5 波 / 正規隊員 7 波 / 使徒級 9 波（敌血更厚、弹速更快、耐久更少），分数按难度记录最佳。

### 使徒来袭 · 塔防（策略塔防 · 新玩法）

- 使徒沿固定通道从**侵入点**扑向 **NERV 本部**，你沿线布防拦截；撑过全部波次即作战完成，本部耐久归零则防线失守；
- **操作**：点击**空地**弹出建造菜单选炮台，点击**已有炮台**升级（最高 Lv.3）或拆除（返还 70% 经费）；`Esc` 取消、数字键 `1–4` 快捷建造、空格提前呼叫下一波；
- **四类炮台**：**零号机·绫波**（减速控场，便宜）／**二号机·明日香**（高射速近战）／**阳电子炮台**（超远程高伤，慢）／**AT 力场发生器**（范围脉冲，专打蜂群）；
- **五型使徒**：小型（快、皮薄）／中型／**重装**（护甲厚，减伤明显）／**分裂**（击破裂成两只小型）／**Boss**（高护甲高血量，漏进本部扣 5 点）；
- **经济与波次**：击破得经费，**提前出击**可把剩余备战时间按 0.25 秒 = 1 经费兑换；`⏩` 可切 1×/2× 速度；
- **三档难度**：見習い 15 波 / 正規隊員 20 波 / 使徒級 25 波（Boss 波分别在第 8/15、10/20、10/18/25 波）；
- **战术**：拐角处布防性价比最高（停留时间长）；**升级远比重数量重要**——一座 Lv.3 零号机约等于三座 Lv.1；重装使徒要靠阳电子炮的高单发伤害，分裂使徒交给 AT 力场。

### 使徒扫雷（明日香 × 绫波丽）

- 地雷即「使徒」，随机归属双主角（蓝=绫波丽担当 / 红=明日香担当），插旗 = NERV 旗；
- 三档规模：見習い 9×9·10、正規隊員 16×16·40、**使徒級·S2 36×36·200**（大棋盘按可用宽度自适应格子，窄窗口下容器内横向滚动）；
- 首击安全（首次翻开 3×3 无雷并延迟布雷）、数字区双击/中键快速展开（chord）；
- 踩雷触发「PATTERN: ORANGE」全屏警报，清空则 AREA CLEARED；计时 + 各难度最佳纪录。

### 蜘蛛纸牌（双姝扑克）

- 10 列 · 单花色（红桃）× 8 套 = 104 张；前 4 列 6 张、后 6 列 5 张开局，余 50 张储备分 5 轮发牌；
- 点击暗牌翻开；点击明牌选中从顶开始的连续段，点目标列放置（空列或目标顶牌比段顶大 1）；
- 列内从顶向下每张 +1 的连续段可整体移动；凑齐 K→A 完整 13 张自动收牌 +100；
- ↩ 撤销、🃏 发牌（5 次每列顶 +1）、💡 提示、❓ 玩法说明、♻ 重开，8 套收齐获胜；
- 牌面素材为双姝扑克全套（assets/spider/cards）；
- 规则为标准蜘蛛：列顶起的同花降序段（K,Q,J…或单张）可整段拖动到空列或
  “目标列顶牌比段顶大 1”的列；同花连续 13 张（A→K 或 K→A 任一方向）自动收套。

### AT 力场弹球（物理技巧 · 新玩法）

- 用 **AT 力场挡板**把阳电子炮弹向使徒装甲，**打光本关全部装甲块**即过关；关卡全部通关则作战完成，备用球耗尽则失败；
- **操作**：← → / A D 移动挡板，也可直接移动指针或手指到想去的横向位置；**空格 / 点击**发射（球会在挡板上待机）；
- **反弹角度**：球打在挡板**不同位置**会改变反弹角——越靠边越斜，可以用来把球送向侧边死角；挡板横移会给球带上旋转；
- **三档装甲**：紫色＝一击碎（装甲 10 分）／橙色＝两击（重装 25 分）／金色＝三击（核心 60 分，分值最高）；
- **同步率**：击破装甲累积（重装 / 核心给得更多）、随时间回落、漏球 -12%；**满 100% 进入暴走 6 秒**——阳电子炮获得**穿透**（连续贯穿装甲不反弹）、分数翻倍、屏幕泛红，并实时驱动右侧装饰栏面板；
- **道具**（击破有概率掉落）：**W** 力场加宽 14s / **M** 三球分裂 / **P** 穿透弹 7s / **S** 同步率 +18%；
- **三档难度**：見習い（球慢 · 挡板宽 · 3 球 · 5 关）／正規隊員（6 关）／使徒級（球快 · 挡板窄 · 2 球 · 6 关，重装更多）；逐关球速 ×1.08、重装比例上升。

## 五珠对弈（新玩法）

打开页面在"选择玩法"中点 **五珠对弈**（游戏中也可随时点 `🎮 玩法` 切换）。

- 9×9 棋盘，你执**绫波丽珠**、AI 执**明日香珠**，轮流落子；
- 任意横竖斜方向连成 **5 珠即得分并消除**：连长 × 10 分，一条子同时组成两条线双倍计；
- 也可以抢在对方连成五珠前用珠子**封堵**；
- 棋盘填满后比分**高者获胜**，结算含胜利 / 惜败 / 平局三种结果。
