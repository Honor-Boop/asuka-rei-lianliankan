# EVA 连连看 · 明日香 × 绫波丽

一个本地网页小游戏合集：以《新世纪福音战士》明日香与绫波丽为主题的**连连看**，
外加一个 **2K 壁纸图库**，壁纸会作为两个页面的自动轮换背景。

## 打开方式

直接双击 `index.html`（纯静态页面，无任何依赖、无需服务器）即可游玩；
或在本目录起一个静态服务器后访问 <http://127.0.0.1:8765/index.html>：

```bash
python -m http.server 8765
```

## 页面

| 文件 | 说明 |
| --- | --- |
| `index.html` | 连连看游戏。8×6 棋盘、12 种牌面（两位角色各 6 种），发牌时保证整盘可解 |
| `gallery.html` | 壁纸图库。按角色筛选、灯箱大图浏览（←/→ 翻页、Esc 关闭）、下载原图 |
| `background.js` | 两页共用的背景轮换组件：每 12 秒淡入淡出切换一张壁纸，提供 `🖼 换背景` 按钮（`window.__bgNext()`） |
| `wallpapers/` | 15 张 2K（2560×1440）以上壁纸 + 缩略图 + `manifest.js` 清单 |
| `images/` | 连连看牌面用的 160×160 头像图 |
| `scripts/` | 图片抓取与处理脚本（Python + Pillow） |

## 游戏规则与功能

- 点击两张**相同图片**的牌，若能用**不超过 2 个拐点**的线连通（可以绕棋盘外圈）即消除；
- 连击：5 秒内连续消除，得分翻倍（+10 → +20 → …）；
- 💡 提示 ×3、🔀 洗牌（无可用配对时自动洗牌）、↻ 重开、🖼 换背景、🔊 音效开关；
- 胜利后记录最佳用时（localStorage）。

## 维护壁纸库

重新抓取/扩充壁纸：

```bash
python scripts/fetch_wallpapers.py   # 默认每角色下载 10 张候选，人工筛选后删除不要的
python scripts/fetch_wallpapers.py   # 再跑一次可重建 thumbs 与 manifest.js
```

壁纸来源为 safebooru 公开 API（safe 分级、宽高 ≥ 2560×1440、按站点评分排序）。
